# 🤖 Auto Accept Request Bot (Unlimited)

A powerful Telegram bot that **automatically accepts join requests** for  
**unlimited channels and groups**.

> Just add the bot as **Admin** — it will handle everything automatically.

---

## 🚀 Features

- ✅ Auto-accept join requests
- ✅ Works for **unlimited channels**
- ✅ Works for **unlimited groups**
- ✅ Welcome message via **DM**
- ✅ No need to add channels manually
- ✅ Works after restart
- ✅ GitHub & Hosting App friendly
- ✅ Stable & lightweight

---

## ⚙️ Requirements

- Python 3.9+
- Telegram Bot Token
- Telegram API ID & API HASH
